# Computer Vision Lab Task 01

## images.py Script

The `images.py` script uses the **OpenCV (cv2)** library to load an image from the `Images` folder and display it on the screen. It demonstrates the basic process of reading and displaying an image using Python and OpenCV.

## Images Folder

The `Images` folder contains two image files selected for this lab task. These images are used to test the image-loading functionality of the `images.py` script.
